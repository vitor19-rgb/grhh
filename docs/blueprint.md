# **App Name**: ConsuOnline

## Core Features:

- Patient Authentication: User authentication for patients with registration and login functionalities, managed locally.
- Admin Authentication: Admin authentication with predefined credentials.
- Patient Dashboard: Patient dashboard with options to schedule appointments and view upcoming appointments.
- Admin Panel: Admin panel to manage doctors, set schedules, and manage patients.
- Appointment Scheduling: Schedule appointments by selecting available date and time.
- Local Storage Management: Data storage in localStorage for users, doctors, and appointments.
- Smart Conflict Detection: Use a tool to analyze patient input for common scheduling conflicts (e.g., overlapping appointments), generating user-friendly warnings that assist the patient in picking a more suitable time.

## Style Guidelines:

- Primary color: Teal (#008080) for a calming and professional feel, drawn from the app's association with healthcare.
- Background color: Light teal (#E0F8F8), providing a soft and clean backdrop for the app's content.
- Accent color: Pale orange (#FFB347) for key CTAs, enhancing readability and drawing user's attention, analogous to the primary color.
- Body and headline font: 'PT Sans' (sans-serif) to ensure ease of reading for users with varied levels of digital literacy.
- Simple, easily recognizable icons for key actions to support intuitive navigation for all users.
- Clean and simple layout with large, clear buttons and elements to accommodate users with low digital literacy.
- Subtle animations or transitions to confirm actions without being distracting or confusing.
